## 변경

- 목과 머리의 위치를 월드 Z로 5 올렸다. Neck / Head / HeadTop_End는 방향·길이·roll을 유지한 채 같은 벡터로 이동했다.
- 머리는 머리 시작점 주변에서 균일하게 약 0.932419배로 조정해 T포즈 키를 정확히 170으로 유지했다.
- Arm / ForeArm 영향 점은 뼈 축 방향 반지름을 약 0.8배로 줄였다. x=42~46은 부드럽게 원래 크기로 전환하고, |x|>46인 손 좌표는 전부 유지했다.
- UpLeg / Leg 영향 점은 반지름을 약 0.88배로 줄이고 발목 경계에서는 점진적으로 전환했다. 신발과 바닥 접촉점은 유지했다.
- 기존 최대 4개 가중치를 정규화했다. 원래 머리 영역은 Head 1.0으로 정리했다.
- 옷 파일의 몸 메시와 여성 뼈대 rest 위치를 함께 동기화했다. 30개 옷 오브젝트의 메시와 남자 원본은 변경하지 않았다. 옷 다시 맞추기는 별도 작업이다.

## 파일

- `prepared/`: 검증을 마친 두 Blender 파일.
- `backups/`: 작업 전 원본 두 파일과 Blender의 저장되지 않은 상태를 포함한 작업 직전 사본.
- `renders/`: Face Cam 설정과 연두색 배경으로 촬영한 남녀 비교. 걷기 1/9/17/25, 뒷모습, 대기 150, 작업 전 대기 150.
- `baseline.json`, `verification.json`: 좌표·가중치·프레임별 바닥 높이 확인.
- `render-status.json`: 렌더마다 실제로 평가한 발 뼈 위치 기록.
- `clothes-sync.json`: 옷 파일 동기화 확인.
