# 여자 v3 — 어깨 연결·상체 길이·허리와 골반 수정

사용자 요청: 어깨 위에 한 겹 더 보이는 선을 정리하고, 상체를 짧게 하며, 옷의 품 대신 몸 메시의 허리를 잘록하게 하고 골반을 넓힌다.

- 이전 목 조정의 영향을 함께 받아 올라간 어깨 혼합 가중치 구간 146개 점을 재조정했다. 추가로 64개 점의 목~어깨 경사를 하나로 정리했다.
- 몸통 길이를 줄이고 상체와 머리·팔을 연결된 위치로 옮겼다. 머리 크기·다리 길이를 다시 축소하지 않았다. 기본 키는 170 → 166.5다.
- 허리 폭은 측정 단면에서 약 36.90 → 33.67(약 8.8% 감소), 골반은 약 42.31 → 46.24(약 9.3% 증가).
- 머리·머리카락의 형태, 가슴 앞뒤 곡면, 손의 형태는 유지했다. 손은 상체와 함께 Z -3.5로 이동했다.
- 뼈 방향과 roll, 애니메이션 곡선을 보존했다. Spine1·Spine2는 부모 관계를 유지하면서 연결점 고정을 해제해, 위치 조정으로 로컬 회전축이 달라지지 않게 했다.
- UV·토폴로지·텍스처·재질과 원본 남자 캐릭터는 유지했다. 복셀 리메시는 사용하지 않았다.
- 옷 파일에는 같은 몸 메시와 뼈대 위치를 동기화한다. 별도 옷 메시의 몸 맞춤은 수행하지 않는다.

`verification.json`은 좌표·가중치·프레임별 바닥 높이 검사, `renders/`는 남자와 같은 동작의 비교 렌더다. `backups/`에는 직전 두 파일과 저장되지 않은 Blender 상태까지 포함한 사본이 있다.
